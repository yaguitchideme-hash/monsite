Projet TPE - Gestion de Site Web

Description
Ce projet est une application web développée en PHP permettant la gestion d’un site web.
Il inclut un système d’authentification, un espace administrateur et la gestion des utilisateurs.

 Objectifs
- Créer un site web dynamique
- Implémenter une base de données MySQL
- Gérer les utilisateurs (connexion / inscription)
- Mettre en place une interface d’administration

 Technologies utilisées
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

Fonctionnalités principales
-  Authentification (login / register)
-  Gestion des utilisateurs
-  Tableau de bord administrateur
- Pages dynamiques (contact, accueil…)

 Base de données

Le fichier database.sql est inclus dans ce projet.

Installation de la base :
1. Lancer XAMPP
2. Démarrer Apache et MySQL
3. Aller sur http://localhost/phpmyadmin
4. Créer une base de données (ex: tpe_db)
5. Importer le fichier database.sql

---

Lancer le projet

1. Copier le projet dans le dossier : htdocs/
sitenouveau │── index.php │── login.php │── register.php │── db.php │── /admin │── /images │── database.sql │── README.md
2.ouvrir le navigateur et aller sur:http://localhost/sitenouveau
